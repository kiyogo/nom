<p align="center"><b>Online web edition of the Nom office suite.</b></p>

### Overview

Nom Web is the online edition of the Nom office suite, offering a flexible workspace accessible from any modern web browser for writing and document productivity.

### Key Capabilities

* Instant Access: Open and work on documents anywhere without local installation.
* Distraction Free Workspace: Clean layout focused on productivity and readability.
* Accurate Typography: Crisp text rendering and responsive page flow.
* Easy Sharing: Simple export and document management tools.
