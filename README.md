### Overview

Nom is a modern office suite built from the ground up for speed, elegance, and reliability.

It combines high performance native desktop capabilities with a flexible web workspace. Every component is designed to launch instantly, respond smoothly, and respect system resources.

### Core Pillars

* Ultra Fast Startup: Applications open in milliseconds with immediate responsiveness.
* Lightweight Footprint: Minimal memory usage even with demanding workloads.
* Unified Experience: Consistent interface and smooth workflows across desktop and web.
* Pure Native Power: Hardware accelerated rendering with smooth frame rates.
* Privacy by Design: Local first architecture keeping your data under your control.
* Modern Aesthetics: Clean design following fluent typography and responsive layouts.

### Performance Comparison

| Metric | Nom Desktop | Microsoft Office | LibreOffice | Web Office Apps |
|---|---|---|---|---|
| Startup Time | < 50ms | 2 to 5s | 3 to 6s | 2 to 8s |
| Memory on Launch | ~14 MB | ~150 MB | ~180 MB | ~300 MB |
| Runtime Overhead | Pure Native | Native C++ | Native C++ | Heavy Browser Engine |
| Binary Size | ~9 MB | Gigabytes | Hundreds of MB | ~150 MB |

### Platform Editions

Nom provides two unified editions:

* Nom Desktop: Native desktop workspace built for speed and system integration
* Nom Web: Flexible online workspace accessible from any modern browser

### Feature Matrix

### Design Philosophy

Traditional office software has grown heavy, slow, and resource intensive over decades. Many modern alternatives wrap web browsers inside desktop containers, leading to high memory usage and sluggish performance.

Nom takes a different path. It is engineered with modern systems programming to deliver native speed, instant cold starts, and minimal resource consumption. Whether working on local desktop files or collaborating on the web, Nom provides a fast and focused environment.
