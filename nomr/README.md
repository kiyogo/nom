### Overview

Nom Desktop is engineered for high performance, instant startup, and seamless integration with modern desktop operating systems.

### Key Capabilities

* Fast Native Performance: Built with high performance native graphics for smooth interaction.
* Efficient Resource Usage: Sparse memory structures ensure lightweight operation at all times.
* Fluent Interface: Clean visual design with modern typography and window controls.
* Local First Security: Full control over your local documents with zero tracking.
